# Правила за работа — Ivanov Tools
- Owner решава продуктовия обхват. Разбиране → конкретно предложение → одобрение → изпълнение и проверки → отделно одобрение за сливане.
- Работи в отделен branch/PR преди main; кратки задачи една по една. Не рестартирай завършената работа.
- Обяснявай кратко на човешки език. Представяй задачите с номера и чекове.
- Всички нови оферти/сравнения/разписки само EUR. Старите BGN записи се преобразуват правилно; не сменяй само надписа на валутата.
- Датата в документа е редактируема, защото датата на подписване не е известна предварително.
- Район на работа и сайт върху документа са отделни избори. Ръчният избор на сайт не се презаписва при смяна на района.
- English/Deutsch изборът определя адреса, а не превежда документа.
- Нов код се проверява с изолирани примерни данни; тестов файл или branch не означава изолирана база. receipts_test.html използва реалната Firebase база.
- Не променяй база, auth, правила, Cloudflare bindings/secrets/cron или публични сайтове извън изрично разрешения обхват.
- Не предлагай като липсваща функция вече наличните аванси/плащания/остатък. Първо прочети съответния инструмент и връзките му.
- След всяка задача актуализирай State и Handoff с одобрено, изпълнено, проверено, ограничения и точен NEXT. Непровереното се описва като непроверено.
